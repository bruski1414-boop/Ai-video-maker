# Veyra Studio

A simple static web app for experimenting with free community AI image and video generation.

## Run it
Open `index.html` in a browser, or publish this repository with GitHub Pages:
1. Open the repository **Settings**.
2. Go to **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main`, folder `/(root)`, then **Save**.
5. Wait for GitHub Pages to publish and use the URL shown on the Pages settings screen.

## Free generation
- **Images:** Pollinations public image endpoint.
- **Video:** public Hugging Face Gradio Space for prompt-to-video.

## Important limitations
This is a prototype, not an unlimited commercial AI service. The image and video models are hosted by third parties and may change, queue, rate-limit, or temporarily stop working. Free GPU capacity is shared. Generated content quality and waiting time vary. Do not upload private or sensitive material.

## Troubleshooting
If video generation fails, the community Space may be asleep, busy, have changed its API, or block browser requests. Try later. This app does not own or control the model hosting.

No paid API key is configured or required in this prototype.
